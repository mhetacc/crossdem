Lexical Diversity (MTLD)

MTLD (Measure of Textual Lexical Diversity) scores each speech by how long a run of text can go before its type-token ratio drops below a fixed threshold: higher values mean a more varied vocabulary.

BoxPlot shows the distribution of per-speech MTLD for each Prime Minister, ordered by median by default. Line and Trend map each speech's date onto 0–100% of that politician's own career span: Line takes the median MTLD of speeches within ±4 percentage points of each step, while Trend fits a linear or quadratic regression, optionally with a 95% bootstrap confidence band.
